# Getting Support

Thank you for using HCL Roles! This document outlines the ways you can
get help.

## Available Resources

### Documentation

- **[README](README.md)** — what the collection is, how to consume it via
  release artifacts, and how it integrates with the Core Provisioner
- **[CONTRIBUTING](CONTRIBUTING.md)** — role conventions, lint requirements,
  and the release flow
- **Per-role READMEs and `meta/argument_specs.yml`** — each role documents
  its variables, behavior, and any subsumption notes

### Issues and Bug Reports

- **[GitHub Issues](https://github.com/STARTcloud/hcl_roles/issues)** —
  report bugs or request features
- Use the appropriate issue template and search existing issues first to
  avoid duplicates

## Support Expectations

The collection is maintained with limited development resources:

- **Response time**: usually a few days, but this varies with workload
- **Priority**: security issues and broken releases receive the highest
  priority
- **Feature requests**: evaluated against need and available time

## Getting Quality Help

### For Bug Reports

1. **Use the bug report template**
2. **Identify the role** and collection version
3. **Include specifics** — target OS, task output (secrets redacted), and
   how the role was invoked (provisioner, playbook, ad-hoc)

### For Questions

1. **Check the README, CONTRIBUTING, and the role's README first**
2. **Search existing issues**
3. **Be specific** about what you're trying to achieve

## Contributing Back

The best way to improve support for everyone:

- **Document solutions** you find to help others
- **Contribute fixes** when you solve issues
- **Improve documentation** based on your experience

See our [Contributing Guide](CONTRIBUTING.md) for more information.
